# 八字 × 紫微 × 太乙 合盤工具 v0.9.29

一份工具、一次輸入，同時驅動八字、紫微與太乙排盤，並將三法的人生曲線疊在同一條西元年軸上比對。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 父頁：共用輸入表單＋三分頁（重疊曲線／八字盤／紫微盤）＋重疊圖繪製 |
| `bazi.html` | 八字工具＋合化洩氣校正喜用神邏輯＋文末橋接 script（merge-bridge v1） |
| `ziwei.html` | 原紫微工具**原封不動**＋文末附加橋接 script（merge-bridge v1） |
| `bazi-engine.js` / `ziwei-engine.js` / `solar-lunar.js` | Node 用引擎檔；八字引擎與 HTML 內嵌版保持同源 |
| `vendor/jspdf.umd.min.js` | 隨工具封裝的 PDF 產生元件；離線開啟也可輸出報告 |
| `test-children.js` / `test-parent.js` | jsdom 測試（`npm i jsdom` 後 `node test-children.js && node test-parent.js`） |

部署：整個資料夾放上 GitHub Pages 即可，入口為 `index.html`。三個子頁仍可單獨開啟使用，原功能完全保留。

## v0.9.29 曆書延長至 2100（節氣表同源化）

### 問題
`solar-lunar.js`（獨立檔，與太乙工具同源）自始即含 **1930–2100** 精確節氣表，但 `bazi.html` 與 `ziwei.html` 各自**內嵌了一份舊表（1930–2050）**，加上 M2 防護註記、輸入框 `max`、截斷說明皆硬寫 2050，導致八字逐年曲線在 2050 截斷（1976 年生者只看得到 74 歲）。

### 修正（僅換資料、不動計分）
- `bazi.html`、`ziwei.html` 內嵌 `PRECISE_TERM_DATA` 換為 1930–2100（171 年，與 `solar-lunar.js` 逐年比對：重疊 121 年 0 差異）。
- `bazi-engine.js` / `bazi.html` M2 防護本就以「資料探測」判斷（`getTerm(year,3)` 為 0 即擋），無需改邏輯；僅更新註記與錯誤訊息為 1930–2100。
- `index.html` / `bazi.html` 輸入框 `max` 與驗證訊息改 2100。
- 逐年曲線自然延伸至各盤年齡上限（1976 生 → 2077；1988 生 → 2097），`annualTruncated` 於 2100 內為 false。

### 行為後果（非 bug，測試已更新）
1. **太乙流年高低點「各取 6 組」**：2051 年後的高低點參賽，會把部分近年點擠出前六（實測 1976-10-14 亥時女：2024 高點被 2063、2071 擠出）。**待裁定**：上調組數（如 8）或改「今年起前後 N 年內取 6 組」。
2. **財運訊號六十年迴響**：同干支流年於 60 年後再次命中（如 2007 丁亥 → 2067 丁亥），屬正常。

### 驗證
`node test-children.js && node test-parent.js` 全數通過；引擎抽驗 2051 辛未、2060 庚辰、2078 戊戌、2100 庚申年柱正確，2101 明確拋錯。

### 契約

## v0.9.28 八字可靠度傳遞、可信度扣反向、財運訊號層

### 一、八字可靠度係數（父頁新增，改動範圍僅 index.html）

八字曲線的錯誤特性是「離散翻面」——喜用神一旦判反，整條線近似取負，不是連續誤差。八字端自 v0.9.22 起已能標示自己的把握程度，但父頁先前完全未讀取，導致臨界盤與明顯盤在 A／B／C 分級中權重相同。

`baziReliabilityOf()` 依下表換算係數，於 `anchorBandGrade()` 之前同時乘上八字的 `score` 與 `opposition`（不可靠的線，其反對同樣不可靠）；折扣前原始值保留於 `scoreRaw` / `oppositionRaw`。紫微與太乙不依賴喜用神，**不套用**本係數。

| `strength.confidence` | 係數 |
|---|---|
| 明顯 | 1 |
| 特殊格局（已正式切換的明確從格／專旺／化氣） | 1 |
| 偏臨界 | 0.8 |
| 臨界 | 0.6 |

另：`yongShen.alternatives` 非空（存在疑似格備選喜忌）時再乘 0.75，下限 0.5。

畫面於係數 < 1 時顯示「八字可靠度 XX%」小標，折扣不隱形。

### 二、可信度改為「支持減反向」

舊版 `anchorBandConfidence()` 對 B、C 級回傳 `max(bazi.score, ziwei.score)`，完全不扣反向證據；加上 B 級容許反向高達 69（A 級要求 < 35），會把「八字支持 72、紫微反向 65」顯示為 72%。

新公式：`conflict` 分支語意不同、維持 `min(opposition)`；其餘先各法取 `max(0, score − opposition)`，A 級取兩法較小者、B／C 級取較大者。

`anchorBandGrade()` 的 70／35 門檻、`ANCHOR_CONFIG`、`TURN_CONFIG`、`DEADBAND` 均未更動。實測 1976-10-14 亥時女：分級一格未變，可信度普遍下降（大限 2018–2037 由 78% → 33%；大限 2038–2043 由 67% → 9%）。

### 三、財運訊號層（獨立訊號，`affectsCurve:false`）

新增獨立卡片「財運訊號」，**完全不參與曲線計分與 A／B／C 分級**。

- **八字財運訊號**（`bazi.html` 橋接內計算）：該大限或流年柱同時滿足 ①天干五行屬喜用神 ②地支為「年干」或「日干」的祿神。身強、身弱共用同一條件——旺衰差異已由喜用神本身承載（身強與身弱取到的喜用神不同，條件①自動區分），故不另立分支；每筆仍記錄 `strengthLevel` 供日後回查。祿神一律以引擎既有 `getTwelveStage()` 反查臨官位取得，**未另立對照表**。
- **紫微財運訊號**（`ziwei.html` 橋接內計算）：武曲／太陰／天府之一，於該大限（取大限宮干四化）或該流年（取流年天干四化）化祿，且該星本命落宮恰為同層盤的命宮、財帛宮或田宅宮。宮位由既有 `palaceZhi[k] = (命宮地支 − k + 12) % 12` 推得（命宮 k=0、財帛 k=4、田宅 k=9）。
- **雙法財運共振**：兩法各自在子頁換算成西元年區間（八字實歲、紫微虛歲，各用自己的慣例），父頁只取交集；大限層比區間交集、流年層比同一西元年。

三者資料契約 `xiaoliu.wealth-signal/v1` 與 `xiaoliu.wealth-resonance/v1`，皆帶 `affectsCurve:false`。

### 四、契約版本
