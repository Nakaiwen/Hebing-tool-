# qimen-tool　奇門遁甲・時家轉盤排盤　v0.3.0

- `qimen-engine.js`　排盤引擎（置閏法定局、轉盤、九星／八門／八神、格局：青龍返首、飛鳥跌穴、玉女守門、乙／丙奇得時遇甲、天地人三遁、伏吟反吟）
- `index.html`　網頁殼（日盤十二時辰帶＋九宮＋青龍返首區間掃描），與 `solar-lunar.js`、`qimen-engine.js` 同目錄即可開
- `qimen-cli.js`　Node 命令列：`node qimen-cli.js 2026-09-05 [時辰序0-11]`／`node qimen-cli.js scan 起 迄`
- `solar-lunar.js`　自 bazi-tool 複製（節氣 1930–2100、日柱、時柱）
- `置閏表-1990-2100.txt`　引擎算出的閏局起始日，供對帳

## 輸出契約 xiaoliu.qimen-chart/v1
`computeDay(y,m,d)` → `{ schema, method, date, dayGanZhi, term, yuanName, ju, dun, juLabel, chao, chaoJieLabel, leap, fuTouDate, hours[12] }`
每時辰：`{ hourGanZhi, hourRange, xunShou, zhiFu{star,from,to}, zhiShi{gate,from,to}, kong, palaces{1..9:{diPan,tianPan,tianPan2,star,gate,god,kong}}, patterns[], flags }`

## 判格規則（v0.3.0，依御定奇門寶鑑對帳收斂）
通則：甲＝當旬旬首儀；中宮寄坤只是顯示，判格看真實加臨的地盤；寄坤帶來的天盤干不參與判格。
- 青龍返首：值符真實加臨之宮地盤為丙；時干在中宮者不成格（只標符伏吟）
- 飛鳥跌穴：天盤丙加地盤旬首儀；旬首儀在中宮且時干不在中宮時，坤宮視為兼有；時干丙入中宮時標於旬首儀所在宮（值符本宮）
- 玉女守門：值使門落宮地盤為丁
- 乙／丙奇得時遇甲：天盤乙加戊己、天盤丙加庚辛
- 九遁：天遁 生門＋丙＋（地盤丁或九天）；地遁 開門＋乙＋（地盤己或九地）；人遁 休門＋丁＋太陰；風遁 三吉門＋乙落巽；雲遁 三吉門＋乙（地盤辛歸虎遁、坎宮歸龍遁）；龍遁 休門＋乙臨坎；虎遁 生門＋乙加辛，或休門臨艮＋乙加辛；神遁 生門＋丙＋九天；鬼遁 杜門＋丁＋（九地或地盤癸）
- 三詐：三吉門＋陰神＋三奇，缺一不可——真詐 太陰、重詐 九地、休詐 六合
- 五假（寶鑑定義 vs 實際標註衝突處，以標註為準）：天假 景門＋丙丁＋九天（定義含乙，但 09-07 戊辰巽／庚午艮不標）；地假 杜門＋丁癸＋（九天／太陰／六合）（定義含己，但 09-06 丁巳坎不標）；人假 驚門＋壬癸、八神不限（定義只九天，但 09-07 丙寅離螣蛇有標）；神假 傷門＋丁己癸＋（九地／六合）；鬼假 死門＋丁己癸＋（九地／六合）（定義只九地，但 09-07 乙丑坎六合有標）
- 減力標記（忌，不抵銷吉格，供判斷）：符伏吟／符反吟（值符落本宮／對宮）；門迫（門克宮：休入離、生死入坎、傷杜入坤艮、景入兌乾、驚開入震巽）；六儀擊刑（天盤戊震、己坤、庚艮、辛離、壬巽、癸巽）；入墓（天盤甲乙癸坤、丙戊乾、丁己庚艮、辛壬巽）
